# Blue Ivy Group - redesign concept (demo)

A static redesign concept for blueivygroup.in (Mumbai construction, interiors and redevelopment firm).

- Static HTML/CSS/JS, no build step. GitHub Pages serves the repo root.
- PWA: `manifest.webmanifest` + `sw.js`.
- SEO: per-page titles/descriptions, Open Graph, canonical URLs, JSON-LD LocalBusiness/GeneralContractor markup, `sitemap.xml`, `robots.txt`.
- Sections awaiting confirmed company information carry an "Under construction" badge. Nothing unverified is published as fact.

Demo only - not the official site.
